# Jornada 15-16/jun/2026 — do zero à voz do Pedro funcionando

Resumo das ações, experimentos e motivos. Resultado final: **modelo pt-BR (WER 21%) + voz do
Pedro falando pt e parando direito (WER 17%, 14/14 sem balbúcio)**.

## 🔬 Experimentos de treino (o "o quê" e o resultado)

| Experimento | Config | Por quê | Resultado |
|---|---|---|---|
| **cml_base** (Estágio A) | CML, LR 2e-4, 60min | baseline: CML ensina pt? | WER 116% (mediana 70%) — **balbuciava** |
| **tag_base / mix_base** | TAGARELA / mix, 60min | comparar fontes de dados | ❌ crash (shape mismatch — clipes curtos/texto longo) |
| **cml_long** ⭐ (BASE-PT) | CML, **LR 5e-4, 180min** | Head of ML: LR maior + treino longo | **WER 21%** — modelo pt que **funciona** |
| **Stage B v1** (voz) | sobre cml_long, 2e-4/90min, 12s-pad | clonar a voz do Pedro | WER 73% — voz ok mas **balbucia (0/14 para)** |
| **Stage B v2** | real-audio fix, 2e-4/90min | testar o fix de áudio real | WER **300%** — **overfit** (memorizou, destruiu o pt) |
| **Stage B v3** | gentil, LR 5e-5, 15min | corrigir o overfit | WER 85% — menos overfit, ainda balbucia |
| **EOS-ingênuo** | label do eos = 128003 | supervisionar o "parar" | ❌ CRASH (128003 estoura o depth decoder) |
| **Stage B FINAL** 🏆 | EOS correto + gentil 5e-5 | tudo junto | **WER 17%, para 14/14** — tua voz funcionando |

## 🛠️ Bugs da maratona (o "por que custou tanto")

| Bug | Sintoma | Fix |
|---|---|---|
| **Warmup time-capped** | loss travada ~70, WER 185% | `warmup_steps=20` fixo (era ratio × 99 epochs = LR≈0) |
| **encodec padding+truncation** | crash no preprocess | corta áudio na mão, só padding |
| **Disco cheio (CML inteiro)** | 97% do volume | streaming `decode=False` + clip-count |
| **Prep lento** | GPU ociosa 11min | `decode=False` (lê bytes, decoda na tokenização) |
| **ChunkedArray (Colab)** | crash no cast | bug de versão do datasets — RunPod 3.6.0 OK |
| **Shape mismatch** | crash TAGARELA/mix (clipes curtos) | áudio REAL (cutoff real) + collator por-batch |
| **Truncation de texto** | crash 4% do TAGARELA (texto longo corta áudio) | `max_length 384` + filtro `≤12s` |
| **BALBÚCIO (o bloqueio real)** | 0/14 param, WER inflado | **label do `<|audio_eos|>` = 0** (frame de parada [0]×32) — não 128003 |
| **Stage B overfit** | WER 300% | LR baixo (5e-5) + run curto |
